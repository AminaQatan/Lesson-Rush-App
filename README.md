## Publish on GitHub Pages

1. Create a repository named `Lesson-Rush`.
2. Extract this ZIP on your device.
3. In the repository, choose **Add file > Upload files**. Upload the extracted files and the `worksheets` folder, not the ZIP. Keep `index.html` directly in the repository root.
4. Commit the files.
5. Open **Settings > Pages**. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
6. Wait for GitHub to show the published site link in Pages settings.

For an existing repository, replace the matching files with these updated copies.

## Included

- Build a lesson and Ready packs tabs.
- All 75 daily plans across Levels 1, 2 and 3.
- Worksheets, teaching notes, resources and keys.
- Teacher Name and a native calendar date picker.
- Automatic lesson and print updates, with a separate date for each day.
- Purple and yellow-orange theme.

No build command, API key or server is needed. You can also open `index.html` locally; curriculum data is bundled for offline use. Teacher details and saved plans are stored only in the current browser, so existing saved details on the ChatGPT-hosted website do not transfer automatically.

GitHub Pages serves this static copy without the original site's ChatGPT access controls.

Official setup guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
